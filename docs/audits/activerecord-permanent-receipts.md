# Audit: are activerecord's PERMANENT receipts permanent?

Run 2026-09-17 against `main` @ `eda2443035`. This is a fact-finding audit: it
changes no source. Its follow-up work is filed as 12 stories under RFC 0130
(listed at the end).

## Summary

activerecord has **510 PERMANENT receipts**: 246 `@noRailsEquivalent`, 238
`@missingRailsCall` and 26 `@missingRailsArgs`. These match the RFC 0130 census.
None are in `test-helpers/**`. The audit re-scored each one with its receipt
removed, then read the Rails and trails bodies for every receipt that was not a
plain Ruby core-idiom translation.

**The PERMANENT label is wrong for a large share of the receipts that make an
architectural claim.** Of the 313 names covered by `@noRailsEquivalent`
PERMANENT (counting file-level and interface tags per name they cover):

- **33 REDUNDANT**: the receipt covers no extra surface. The name is Rails-named
  or exempt even without the tag.
- **32 MISFILED**: Rails defines the name, just in a different `.rb` or gem.
- **104 CONVERGEABLE-MISLABELLED**: trails inventions (helpers, registries,
  sync shims, invented error classes) that could be removed.
- **29 RATIFIED**: correctly covered by a CLAUDE.md section.
- **89 GENUINELY PERMANENT**: JS protocols, driver shims, TS-only tooling.
- **26 UNDETERMINED**.

So **169 of 313 (54%) are not permanent**, and only 118 hold up.

For the 264 PERMANENT call and args receipts, a gate proves the call really is
missing from the TS body. The open question was only whether "never" is true:

- **200** are Ruby core-idiom translations (`empty?`, `first`, `fetch`, `size`,
  `lambda.call`…). RFC 0092 deliberately routed these to receipts.
- **8** have no JS analogue at all (`Kernel#load`/`exec`, threads, `sleep`).
- **4** are ratified.
- **32 are CONVERGEABLE-MISLABELLED**: the receipt hides a real behavioural
  difference. The worst case is `ConnectionPool#reap`, whose body is only its
  guard.
- **20 are UNVERIFIED**: they suppress no flag at all, because their pair is
  never compared.

Overall: **201 of 510-equivalent receipts are mislabelled or redundant, 20 are
unverifiable and 26 are undetermined.**

Confidence:

- **High** for REDUNDANT, MISFILED and UNVERIFIED. These are measured, not
  judged.
- **Medium** for the CONVERGEABLE-MISLABELLED and RATIFIED splits. These are
  judged per site from `vendor/rails`.
- **Lower** for the 200-row idiom bucket. Only its `fetch` rows were
  spot-checked (6 of 17 port `h.fetch(:k, d)` as `"k" in h`, which preserves
  stored-nil semantics). The rest were not read one by one.

## Method

### 1. Bulk A/B without a rebuild per tag (`@noRailsEquivalent`)

`parity:api:extra` scores names inside `buildReport`
(`scripts/api-compare/extra-surface.ts:2578`). A receipt only enters through
`collectTaggedEntries` (`:694`), which reads `noRailsEquivalent`,
`noRailsEquivalentInherited` and `fileNoRailsEquivalent` off the TS manifest.
Deleting every tag in the source and rebuilding is therefore the same as
deleting those three fields from `output/ts-api.json` in memory and calling
`buildReport` again. The script below does exactly that for one package, then
looks up the verdict for each originally-tagged key:

- `novel` or `moved`, with its Rails owners.
- `allowed-or-exempt`: the name does not score with the tag removed, so the tag
  is redundant.

It also expands file-level tags into the names they absorb.

Measurements moved as expected. With receipts, activerecord scores
`novel 0 / moved 0 / redundant 0`. Stripped, it scores `novel 260 / moved 110 /
total 370`. Manifests were rebuilt first with
`pnpm build && API_COMPARE_FORCE=1 pnpm parity:api`, and again with `--calls`
for the call artifacts. The extractor's freshness guard passed.

```ts
// scripts/audit-tmp/receipt-ab.ts — run: pnpm tsx scripts/audit-tmp/receipt-ab.ts activerecord > ab.json
// A/B every @noRailsEquivalent receipt in one package by scoring the TS
// manifest with ALL receipts stripped, then looking up each tagged key's verdict.
import fs from "node:fs";
import path from "node:path";
import {
  buildReport,
  collectTaggedEntries,
  allowKeyOf,
  loadConcernHooks,
  buildGlobalRubyCandidates,
} from "../api-compare/extra-surface.js";
const OUTPUT_DIR = path.join(process.cwd(), "scripts/api-compare/output");

async function main() {
  const pkg = process.argv[2] ?? "activerecord";
  const ruby = JSON.parse(fs.readFileSync(path.join(OUTPUT_DIR, "rails-api.json"), "utf-8"));
  const ts = JSON.parse(fs.readFileSync(path.join(OUTPUT_DIR, "ts-api.json"), "utf-8"));
  const tagged = collectTaggedEntries(ts).filter((e) => e.package === pkg);

  const strip = (o: any): void => {
    if (Array.isArray(o)) return o.forEach(strip);
    if (o && typeof o === "object") {
      delete o.noRailsEquivalent;
      delete o.noRailsEquivalentInherited;
      for (const v of Object.values(o)) strip(v);
    }
  };
  const stripped = structuredClone(ts);
  strip(stripped.packages[pkg]);
  stripped.packages[pkg].fileNoRailsEquivalent = {};

  const opts = {
    filterPkg: pkg,
    excludeGlobs: [],
    novelOnly: false,
    topN: 100000,
    concernHooks: await loadConcernHooks(ruby, pkg),
  };
  const base = buildReport(ruby, ts, opts);
  const ab = buildReport(ruby, stripped, opts);
  const verdict = new Map<string, any>();
  for (const f of ab.packages.flatMap((p) => p.extraFiles))
    for (const e of f.extras)
      verdict.set(allowKeyOf({ package: pkg, tsFile: f.tsFile, name: e.name }), {
        ...e,
        rubyFile: f.rubyFile,
      });

  // fuzzy: a novel name whose snake form (minus _ prefix / Bang / is) is a Ruby method anywhere
  const glob = buildGlobalRubyCandidates(ruby);
  const rubyNames = new Map<string, string[]>();
  for (const [p, info] of Object.entries<any>(ruby.packages))
    for (const c of [...Object.values<any>(info.classes), ...Object.values<any>(info.modules)])
      for (const m of [...c.instanceMethods, ...c.classMethods]) {
        const k = m.name
          .replace(/[?!=]$/, "")
          .replace(/^_+/, "")
          .replace(/_/g, "")
          .toLowerCase();
        (rubyNames.get(k) ?? rubyNames.set(k, []).get(k)!).push(
          `${p}/${c.file ?? "?"}:${m.line ?? "?"} ${c.name}#${m.name}`,
        );
      }
  const norm = (n: string) =>
    n
      .replace(/^_+/, "")
      .replace(/Bang$|Q$/, "")
      .replace(/^is(?=[A-Z])/, "")
      .toLowerCase();

  const byFile = new Map<string, any[]>();
  for (const f of ab.packages.flatMap((p) => p.extraFiles))
    byFile.set(
      f.tsFile,
      f.extras.map((x: any) => ({ ...x, rubyFile: f.rubyFile })),
    );
  const expanded = tagged.flatMap((e) =>
    e.fileLevel
      ? (byFile.get(e.tsFile) ?? [{ name: "*", none: true }]).map((x: any) => ({
          ...e,
          name: x.name,
        }))
      : [e],
  );
  const rows = expanded.map((e: any) => {
    const k = allowKeyOf(e);
    const v = verdict.get(k);
    const perm = /^\s*PERMANENT/.test(e.reason)
      ? "PERMANENT"
      : /^\s*CONVERGEABLE/.test(e.reason)
        ? "CONVERGEABLE"
        : "UNCLASSIFIED";
    let bucket = v ? v.kind : "allowed-or-exempt";
    const near = v?.kind === "novel" ? (rubyNames.get(norm(e.name)) ?? []).slice(0, 3) : [];
    return {
      tsFile: e.tsFile,
      name: e.name,
      inherited: !!e.inherited,
      fileLevel: !!e.fileLevel,
      perm,
      bucket,
      rubyFile: v?.rubyFile ?? null,
      owners: (v?.owners ?? []).slice(0, 3),
      near,
      reason: e.reason.slice(0, 160),
    };
  });
  console.error(
    `base: novel ${base.packages[0].totalNovel} moved ${base.packages[0].totalMoved} redundant ${base.tagged.redundant.length}`,
  );
  console.error(
    `A/B: novel ${ab.packages[0].totalNovel} moved ${ab.packages[0].totalMoved} total ${ab.packages[0].totalExtras}`,
  );
  console.log(JSON.stringify(rows, null, 1));
}
void main();
```

### 2. Call and args receipts

`compare.ts` records every suppressed flag in `output/call-mismatches.json` and
`call-arg-mismatches.json`, under `suppressed`, with the tag's reason. The
stale-tag half (`staleCallTags`, `compare.ts:1934`) was 0.

A receipt was parsed from source: file, line, Ruby call and enclosing
declaration. It was matched against `suppressed` by declaration name plus call:

- A match is a real omission. The Ruby method was resolved through
  `rails-api.json`, and its body was grepped for the call.
- No match means the receipt suppresses nothing. `staleCallTags` skips
  uncompared pairs by design, so nothing else notices.

## Findings beyond the buckets

1. **No gate checks REDUNDANT receipts.** `gateRedundant`
   (`extra-surface.ts:2768`) only fires on a written per-name tag that a
   same-file allowed set covers. There are two blind spots:
   - The tag check runs _before_ the interface-exemption check
     (`:2283-2295`), so a tag on an exempt interface name always "matches".
   - Inherited interface members are filtered out of `redundant` (`:2630`).

   The prompt's premise that no gate runs a redundant check is half right:
   `parity:api:extra` has one, `extra:gate` does not, and neither catches these 32.

2. **19 receipts sit off the extracted surface.** They cover module-private
   functions (`relation/finder-methods.ts:327`, `relation/query-methods.ts:1586`,
   `migration.ts:266`, `relation/delegation.ts:271`,
   `relation/predicate-builder.ts:350,353`), type aliases
   (`scoping/named.ts:9,12`, `connection-adapters/abstract/schema-definitions.ts:756,763`),
   a local (`nested-attributes.ts:378`), an `@internal` interface pair
   (`insert-all.ts:30,43`), and `src/sqlite/**` (4 one-line file tags plus
   `sqlite-uri.ts:3,17`). No gate reads them, so each one is an unverifiable
   claim. The helpers among them are CLAUDE.md § No extra abstraction debt that
   the extractor cannot see.
3. **One-line JSDoc.** 170 of the 246 `@noRailsEquivalent` PERMANENT tags and
   121 of the 238 `@missingRailsCall` PERMANENT tags are one-liners. Every
   one-line `@noRailsEquivalent` on a surfaced declaration did register: all
   are in `collectTaggedEntries`. The only non-registering ones are the 19
   above, which fail because of where they sit, not their shape.
4. **CLAUDE.md contradicts the PERMANENT label on two receipts.**
   - `connection-adapters/abstract/connection-pool.ts:546`
     `acquireConnectionSync`: § Schema reflection's _Scope boundary_ says the
     sync lease "stays CONVERGEABLE".
   - `connection-adapters/sqlite3/database-statements.ts:176`
     `acquireStatementLock`: § adapter lock names retiring it as a pending story
     (`retire-sqlite-statement-lock-onto-with-raw-connection`, ready).
5. **Ratified citations that do not fit.**

     functions rather than the sanctioned binding plus `_setX()`. Its readers
     guard and throw an invented error (`associations/association.ts:130-133`,
     `:533-534`), which § Call-time constant resolution forbids by name.
   - `connection-adapters/abstract/query-cache.ts:100` (`computeIfAbsent ←
synchronize`) can only borrow the pool-monitor reasoning. That section is
     scoped to `ConnectionPool`.
6. **`@internal` without a backing private.** 76 `@noRailsEquivalent PERMANENT`
   receipts share a JSDoc block with `@internal`, the shape
   `unbacked-internal-needs-receipt` demands. Of those 76, **56 are in the

7. **Dangling `CONVERGEABLE <story-id>` receipts.**
